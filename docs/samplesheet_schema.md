# Samplesheet schema — `config/samplesheet.csv`

Generated by `scripts/bash/build_samples_metadata.sh` from verified metadata only (`data/metadata/samples_metadata.tsv`). Do not edit by hand; re-run the script.

One row per biological sample (each sample has exactly one SRA run). Comma-separated, header required.

| Column | Type | Allowed values / format | Source | Notes |
|---|---|---|---|---|
| `sample` | string | `STV_free_repN` or `STV_infected_repN`, N = 1–3 | GEO title + characteristics | Unique; used as output prefix |
| `condition` | factor | `STV_free`, `STV_infected` | GEO `virus infection` (`-` → `_`) | Intended DESeq2 reference level: `STV_free` (to be approved with the DESeq2 design) |
| `replicate` | integer | 1–3 | GEO title `repN` | Biological replicate within condition |
| `geo_gsm` | accession | `GSM\d+` | GEO | |
| `run_accession` | accession | `SRR\d+` | ENA / NCBI SRA | Key for downloading reads |
| `library_layout` | enum | `SINGLE` (all rows) | SRA/ENA | No `fastq_2`; workflow must use single-end mode |
| `read_length` | integer | 75 | SRA statistics (avg 75, sd 0) | Informs Salmon k-mer choice |
| `strandedness` | enum | `auto`, `unstranded`, `forward`, `reverse` | — | Currently `auto` = **not verified**; must be resolved empirically (decision D-004) and then replaced by the observed value |
| `ena_fastq_ftp` | path | ENA `fastq_ftp` value as reported (host/path, no scheme) | ENA | Remote source, not a local path |
| `ena_fastq_md5` | hex | 32 hex chars | ENA `fastq_md5` | Verify after download |

## Local FASTQ paths

Local paths are intentionally absent until downloads exist. After an approved download, a `fastq_1` column will be added (convention: `data/raw/<run_accession>.fastq.gz`, relative to the project root). There will be no `fastq_2` column/value: the dataset is single-end.

## Compatibility note

nf-core/rnaseq requires the first columns `sample,fastq_1,fastq_2,strandedness` (<https://nf-co.re/rnaseq/3.27.0/docs/usage>). This project's custom workflow does not need that exact layout, but a converted sheet can be derived trivially if nf-core/rnaseq is ever used as a cross-check.
